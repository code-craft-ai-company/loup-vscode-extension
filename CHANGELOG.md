# Changelog

## 1.20.0

First Marketplace release (preview).

- Syntax highlighting, snippets and a language server for Loup v1.20 source files and package manifests.
- Trace viewer for Loup time-travel recordings (`.ltrace`).
- Run (F5) for the open Loup file, and `loup` tasks with a problem matcher.
- Package dependency view.
